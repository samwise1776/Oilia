# Oilia 🌐

Oilia is a social workspace for developers and everyone.

## Features
- Social feed and posts
- Browser tools
- Everyday utilities
- Three independent desktop implementations

## Languages
- JavaScript — GTK4/GJS
- C++ — GTK4/libadwaita
- Python — GTK4/PyGObject

## Website
https://samwise1776.github.io/Oilia/

## Status
Version 0.0.1 — Early development.

The website currently uses browser-local demo data.
Shared accounts and posts require a secure hosted API.
